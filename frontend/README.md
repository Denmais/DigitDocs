# Invoice App (Frontend)

Frontend-приложение для загрузки PDF-документов, визуального выбора данных и формирования итоговой таблицы с возможностью экспорта и публикации в BI.

Проект реализован на чистом JavaScript без фреймворков, с модульной архитектурой.

---

## 📌 Назначение приложения

Invoice App позволяет пользователю:

1. выбрать тип документа (электроснабжение, водоснабжение и т.д.),
2. загрузить PDF-файл,
3. визуально выделить фрагменты документа (crop),
4. подтвердить / отредактировать значения,
5. сформировать итоговую таблицу,
6. скачать результат в CSV,
7. опубликовать результат во внешнюю BI-систему.

---

## 🧭 Пользовательский сценарий (User Flow)

1. **Тип документа**  
   Пользователь выбирает категорию документа.

2. **Загрузка документа**  
   PDF-файл загружается (локально, без отправки на сервер).

3. **Обработка документа**  
   Backend возвращает:
   - `task_id`
   - список страниц (`pages`)
   - список полей (`fields`)

4. **Выбор данных**  
   Пользователь выделяет фрагменты PDF (crop) для каждого поля.

5. **Результат**  
   Формируется итоговая таблица, доступен экспорт и публикация.
